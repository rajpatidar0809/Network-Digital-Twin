# Network Digital Twin

A beginner-friendly network monitoring dashboard built with Python, Flask, HTML and CSS.

## Features
- Displays sample network devices
- Shows device online/offline status
- Displays sample latency values
- Presents network information in a dashboard

## Run the project
1. Install Python.
2. Open a terminal in this folder.
3. Install Flask: `python -m pip install -r requirements.txt`
4. Run: `python app.py`
5. Open http://127.0.0.1:5000 in your browser.

Note: This educational project uses sample data and does not monitor a real network.
